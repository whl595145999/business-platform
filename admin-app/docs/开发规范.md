## 1. 系统定位

| 项目 | 说明 |
|------|------|
| 项目名称 | business-platform-admin-app |
| 前端脚手架 | [unibest](https://unibest.tech) 4.x |
| PC 端（接口参考） | business-platform-admin-web |

| 目标平台 | H5、微信小程序、App |

**三方对齐原则：**

1. 新增/修改 API → 先查 admin-web 同名文件 → 再在 `src/api` 实现相同路径与方法  
2. 环境变量（CLIENT_ID、加密、RSA）与 admin-web `.env` 保持一致  
3. 权限标识 `perms` 与后台菜单、PC 端按钮一致

## 4. 后端对接规范（与 admin-web 一致）

### 4.1 环境变量

| 变量 | admin-web | 移动端 |
|------|-----------|--------|
| 客户端 ID | `VITE_APP_CLIENT_ID` | `VITE_CLIENT_ID` |
| 接口加密 | `VITE_APP_ENCRYPT` | `VITE_APP_ENCRYPT` |
| RSA 密钥 | `VITE_APP_RSA_*` | `VITE_APP_RSA_*` |
| API 前缀 | `VITE_APP_BASE_API` | H5：`VITE_APP_PROXY_PREFIX`（`/dev-api`） |
| 后端地址 | 代理 target | `VITE_SERVER_BASEURL` |

| 变量 | 说明 |
|------|------|
| `VITE_AUTH_MODE` | `platform`（业务平台认证） |
| `VITE_SERVER_BASEURL` | 如 `http://localhost:8080` |

### 4.2 响应格式

```json
{ "code": 200, "msg": "操作成功", "data": {} }
```

分页列表（无 `data` 包裹时）：

```json
{ "code": 200, "rows": [], "total": 0 }
```

`http.ts` 已统一提取为 `data` 或 `{ rows, total }`，与 admin-web 拦截器行为一致。

### 4.3 认证与请求头

| 项目 | 规范 |
|------|------|
| Token | `access_token`，本地 Key：`App-Token` |
| 请求头 | `Authorization: Bearer {token}` + `clientid`（每个请求） |
| 登录 | `POST /auth/login`，`{ isToken: false, isEncrypt: true }` |

### 4.4 分页

```typescript
// 请求
{ pageNum: 1, pageSize: 10, ...query }

// 响应类型
IPageResult<T>  // { rows: T[], total: number }
```

### 4.5 接口加密（与 admin-web 相同）

| 场景 | 配置 |
|------|------|
| 登录 / 注册 | `isEncrypt: true` |
| 修改个人密码 / 重置用户密码 | `isEncrypt: true` |
| 普通 GET / 一般 PUT | 默认不加密请求体；响应可按响应头解密 |

## 5. API 开发规范

### 5.1 流程

```
1. 打开 admin-web/src/api/{模块}/index.ts
2. 复制路径、方法、参数含义
3. 在 src/api/{模块}.ts 用 http.get/post/put/delete 实现
4. 类型放在 api/types/backend.ts 或 api/types/{模块}/
5. 更新 docs/admin-web接口对照.md
```

### 5.2 用户模块示例（已落地）

```typescript
// src/api/system/user.ts — 与 admin-web system/user/index.ts 对齐
import type { IPageResult } from '@/api/types/backend'
import type { IUserQuery, IUserVo } from '@/api/types/system/user'
import { http } from '@/http/http'

export function listUser(query: IUserQuery) {
  return http.get<IPageResult<IUserVo>>('/system/user/list', query)
}
```

### 5.3 请求选项

```typescript
// 无需 Token
http.get('/auth/code', undefined, undefined, { isToken: false })

// 加密 POST
http.post('/auth/login', data, undefined, undefined, { isToken: false, isEncrypt: true })
```

## 12. 常见问题

**Q：连不上后端？**  
确认 `VITE_SERVER_BASEURL`、H5 代理 `VITE_APP_PROXY_ENABLE=true`，后端已启动。

**Q：微信小程序真机报 `ERR_CONNECTION_REFUSED` / `errcode:-102`？**  
真机上 `localhost` 指向手机本身，不是开发电脑。请：

1. 电脑与手机连接**同一 WiFi**
2. 查电脑局域网 IP（如 `192.168.1.100`）
3. 复制 `env/.env.development.local.example` → `env/.env.development.local`
4. 设置 `VITE_SERVER_BASEURL__WEIXIN_DEVELOP = 'http://192.168.x.x:8080'`
5. 重新执行 `pnpm dev:mp`，微信开发者工具重新预览/真机调试
6. 开发者工具 → 详情 → 本地设置 → 勾选「不校验合法域名、web-view…」
7. 确认后端 `8080` 已启动，且本机防火墙未拦截

**Q：登录 401？**  
`VITE_CLIENT_ID` 须与 admin-web、后台 `sys_client` 一致。

**Q：列表无数据但 PC 有？**  
检查是否用 `IPageResult` 接 `rows/total`；权限 `system:user:list`。

**Q：能用 alova 写业务接口吗？**  
不能。业务统一 `http.ts`。

**Q：微信小程序表单只有值、没有字段名？**  
`@wot-ui/ui` **2.0.8** 已移除 `wd-input`/`wd-picker` 的 `label`；按 [UI组件规范.md](./UI组件规范.md) §5 与标杆 `pages-sub/scm/org/form.vue` 改。或 `@uniapp-dev` 例 4。
