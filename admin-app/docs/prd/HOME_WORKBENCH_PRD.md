# 移动管理工作台（首页）PRD

> **版本**：v1.0 · **端**：`business-platform-admin-app` TabBar 首页  
> **状态**：MVP 已落地（指标占位 + 最近使用本地缓存，业务 API 后续接线）

## 1. 背景与目标

| 项 | 说明 |
| --- | --- |
| 用户 | 供应链企业内部管理员、仓管、运营（移动管理端，非 PDA 现场） |
| 目标 | 登录后快速进入授权功能；感知待办/单据/异常（后期）；减少扫宫格成本 |
| 非目标 | PDA 扫码作业（B8+ `pages-sub/pda`）；C 端营销首页 |

## 2. 页面结构

```text
PageHero（工作台问候 + 轻渐变）
  → 业务指标三卡（待办 / 今日单据 / 异常）
  → 最近使用（有记录时展示，最多 4 项）
  → 应用功能宫格（按权限动态分组，下拉/按钮刷新）
```

## 3. 指标定义（v1 占位，v2 接 API）

| 指标 | 含义 | v1 展示 | v2 数据来源（规划） |
| --- | --- | --- | --- |
| 待办 | 待我审批/处理的单据数 | `0` | 工作流/待办聚合 API |
| 今日单据 | 当日新建或流转的单据数 | `0` | WMS/OMS 日统计 API |
| 异常 | 需关注的差异/告警数 | `0` | 告警/异常单 API |

**规则**：未登录不展示指标区；接口未就绪时显示 `0`，不阻塞首页。

## 4. 最近使用

| 项 | 规则 |
| --- | --- |
| 触发 | 用户从首页宫格点击进入分包页时记录 |
| 存储 | `uni.setStorageSync`，按 `userId` 隔离 |
| 容量 | 最多 4 条，LRU |
| 展示 | 有记录且已登录时展示；路径失效（菜单收回）自动过滤 |

## 5. 与「我的」分工

| 页面 | Hero 主标题 | Hero 副标题 |
| --- | --- | --- |
| 首页 | 你好，{昵称} | {应用短名} · 工作台 |
| 我的 | {昵称} | {角色} · 点击管理账户 |

## 6. 状态

| 状态 | 表现 |
| --- | --- |
| 未登录 | Hero 欢迎文案 + `wd-empty` 引导登录；无指标、无最近、无宫格 |
| 已登录无菜单 | 指标 + empty「暂无可用菜单」+ 刷新 |
| 已登录有菜单 | 指标 + 最近（可选）+ MenuGrid |
| 刷新 | 下拉刷新 + 区块内刷新按钮，重拉 `getRouters` |

## 7. 验收（AC）

- [ ] 未登录不出现三个 `0` 指标
- [ ] 登录后指标文案为「待办 / 今日单据 / 异常」
- [ ] 从宫格进入任意页后返回，首页「最近使用」出现该项
- [ ] 单分组菜单时不重复显示分组内大标题与外层「应用功能」双标题
- [ ] TabBar 页底部内容不被遮挡
- [ ] Hero 与登录页同色系轻渐变
