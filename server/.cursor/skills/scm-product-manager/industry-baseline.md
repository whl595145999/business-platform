# 供应链行业标准基线（绿地实施）

> **用途**：`scm-product-manager` 在 **程序级重建** 或 **Step 2 主数据排序** 时必读。  
> **边界**：只写 **业务依赖与波次**；ER/API/表结构 → [ecommerce-scm-architect](../ecommerce-scm-architect/SKILL.md)。

---

## 1. 实施分层（L0～L5）

行业通用：**先建档、再建账、再跑单、再上高级能力**。

| 层 | 名称 | 典型产出 | 本项目 |
| --- | --- | --- | --- |
| **L0** | 平台底座 | 租户、用户、权限、字典 | `whl-platform-*`（已有） |
| **L1** | 主数据 MDM | 组织、商品、仓库、伙伴、单位 | `wms_org`、`prd_*`、`wms_warehouse` |
| **L2** | 库存账 | 余额、流水、可售口径 | `inv_stock`、`inv_stock_log` |
| **L3** | 作业单据 | 入、出、占、扣、盘点 | `wms_inbound_*`、`wms_outbound_*` |
| **L4** | 交易单据 | 销售/采购订单驱动履约 | `oms_order`、采购单（远期） |
| **L5** | 高级能力 | 调拨、跨组织售卖、批次、结算、PDA | V2+ |

**禁止**：L1 未齐就跑 L3/L4（例：无 SKU 用 demo 字符串跑入出库）。

## 2. 主数据硬依赖（必须先谁后谁）

```text
租户 tenant
  └── 组织 Org ─────────────────────────┐
        │                                │
商品 SKU（集团商品库，不挂组织树）        │
        │                                │
        └──► 仓库 Warehouse ◄────────────┘
                  │
                  └──► 库存账 Stock（org + 仓 + SKU）
                            │
                            └──► 入出库 / 预占 / 订单
```

| 顺序 | 主数据 | 硬依赖 | 缺了会怎样 |
| --- | --- | --- | --- |
| ① | **组织** | `tenant_id` | 无法定义货权、仓归属、调拨边界 |
| ② | **商品** | 无（可与①并行设计，**实现建议①后②**） | 入出库/订单只能假 SKU |
| ③ | **仓库** | 组织 `owner_org_id` / `operate_org_id` | 无法收货、发货、查库存 |
| ④ | **渠道/虚拟仓映射** | 实物仓 | 无法做渠道可售聚合 |
| ⑤ | **伙伴**（供应商/客户） | 可选 | 采购/销售正式化时需要 |
| ⑥ | **单位/批次/库位** | 商品、仓 | 批次效期、精细库位管理时需要 |

**软依赖**：`sys_dept` 用于数据权限，**不等于**货权组织（见 [B1-org/PRODUCT.md](../../docs/domains/wms/prd/B1-org/PRODUCT.md) §5）。

## 3. 推荐实施波次（本项目）

与 [ROADMAP.md](../../docs/ROADMAP.md) 对齐；每波 **PRD 定稿 → 架构师 → 实现** 后再开下一波。

| 波次 | 范围 | 解锁的业务能力 | 明确不做 |
| --- | --- | --- | --- |
| **B1** | 组织 `wms_org` | 组织树、下拉、启停 | 跨组织授权、调拨 |
| **B2** | 商品库 `prd_*` | SKU、类目、效期/配额、条码 | 渠道定价、营销 |
| **B3** | 仓库 `wms_warehouse` + mapping | 选履约仓、虚拟仓映射 | 库位、批次 |
| **B4** | 库存账 `inv_*` | 可用库存、流水 | 渠道配额、批次 |
| **B5** | 入出库 | 收货、发货、占扣 | 跨 org 调拨 |
| **B6** | OMS 订单 | 订单确认驱动出库 | 支付、售后 |
| **B7** | 盘点、同 org 调拨 | 运维闭环 | 跨 org 结算 |
| **B8** | 跨组织售卖、PDA、OpenAPI | 规模化 | 财务对账 |

## 4. 四场景裁剪（Step 1 选型）

| 场景 | L1 优先顺序 | 说明 |
| --- | --- | --- |
| **集团多组织**（本项目） | 组织 → 商品 → 仓 → … | 货权、调拨边界以 org 为锚 |
| **单组织电商** | 商品 → 仓 → 组织可简化 | 卖货驱动，组织常单节点 |
| **制造 + 采购** | 组织/工厂 → 物料 → 供应商 → 仓 | 采购与 BOM 更早 |
| **纯 3PL 仓配** | 货主(组织) → 仓/库位 → 客户货品 | 多货主 WMS |

收到需求时 **先声明场景**，再套 §2 顺序；勿默认所有行业同一顺序。

## 5. 主数据治理（Step 2 / Step 6 必写）

| 项 | 行业惯例 | 本项目建议 |
| --- | --- | --- |
| **编码** | 租户内唯一、可读、稳定 | `org_code`、`sku_code` 等 |
| **启停** | 停用后不可被新业务引用 | `status` 10 启用 / 20 停用 |
| **删除** | 有子节点或被引用则禁止硬删 | 逻辑删除或禁止删除 |
| **树调整** | 改上级需校验环、子树 | 组织 `parent_org_id` |
| **权责** | 谁创建、谁审批、数据 scope | 对接 `sys_dept`、RuoYi 权限 |

## 6. 库存口径（Step 4 行业对照）

| 口径 | 含义 | 典型公式 |
| --- | --- | --- |
| **现有/on-hand** | 账上实物数量 | 入库 − 出库 ± 调整 |
| **可用/ATP** | 可承诺量 | 现有 − 预占 − 冻结 |
| **预占/锁定** | 订单/出库占用 | 确认订单、出库分配时增加 |
| **在途** | 已发未收 | 调拨出、采购在途（V2） |
| **安全/预警** | 补货参考 | 规则引擎（远期） |

WMS 管 **作业**；Inventory 管 **账** — 分工见 [MODULE_RULES.md](../../docs/MODULE_RULES.md)。

## 7. 单据族谱（Step 3 速查）

| 类型 | 示例 | 特点 |
| --- | --- | --- |
| **主数据** | 组织、SKU、仓库 | 无状态机或仅启停 |
| **计划/申请** | 采购申请、调拨申请 | 可审批，不直接动库存 |
| **执行/作业** | 入库单、出库任务、盘点单 | 驱动 WMS 作业 |
| **交易** | 销售订单、采购订单 | 驱动库存预占与履约 |
| **结算** | 内部交易、对账单 | 二期，跨 org |

本期范围 **只列需要的族**，不一次设计全部单据。

## 8. 绿地 vs 迁移

| 类型 | 产品检查 |
| --- | --- |
| **绿地（从 0）** | 按 §2～§3 波次推进；已落地见 [domains/README.md](../../docs/domains/README.md) |
| **迁移/割接** | 额外：历史数据映射、并行运行、回滚、双写期 AC |
| **增量功能** | 读已有 PRD，只跑相关 Step（见 [workflow.md](workflow.md) 入口分流） |
